# Student Management System

A simple **Student Management System** built with **Java** to practice basic **OOP concepts** and **CRUD operations**.

## Features

- **Add Student** — Add a new student.
- **View Students** — Display all registered students.
- **Search Student** — Search for a student.
- **Update Student** — Modify student information.
- **Delete Student** — Remove a student.
- **Exit** — Close the application.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- CRUD Operations

## OOP Concepts Practiced

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- Getters and Setters
- ArrayList
- Loops
- Conditional Statements
- Switch Statements
